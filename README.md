# آکادمی ریاضی | نظام آموزشی دیجیتال

این پروژه یک سیستم آموزشی دیجیتالی برای صنوف هفتم تا دوازدهم است که در زبان دری و فارسی طراحی شده است. هدف آن آموزش مرحله‌به‌مرحلهٔ ریاضی از حساب تا ریاضیات عالی، همراه با تمرین‌های تعاملی، آزمون‌ها، لینک‌های ویدیویی، فورم‌های قابل چاپ و حالت آفلاین است.

## امکانات اصلی
- آموزش درس‌های ریاضی برای صنوف هفتم تا دوازدهم
- بخش‌های حساب، الجبر، هندسه، مثلثات و ریاضیات عالی
- تمرین و آزمون کوتاه تعاملی
- کاربرگه‌های قابل چاپ
- حالت آفلاین با Service Worker
- رابط کاربری رنگارنگ و راست‌چین
- پشتیبانی از زبان‌های دری و فارسی

## اجرا
برای اجرا، در پوشهٔ پروژه یکی از دستورهای زیر را اجرا کنید:

- Linux/macOS:
  python3 -m http.server 8000

- Windows:
  py -m http.server 8000

سپس در مرورگر آدرس زیر را باز کنید:

http://localhost:8000
